DevSecOps CI/CD Dashboard
A lightweight overview of what this repo’s pipeline runs and where to view outputs.
CITestsDocker

On every push/PR, the pipeline runs pytest, builds a Docker image, and uploads artifacts.

  • GitHub Actions runs: Actions
  • Artifacts: open the latest run → Artifacts → download ci-artifacts
SecurityCodeQL

Static analysis using GitHub CodeQL. Results appear under code scanning alerts.

  • Code scanning: Security → Code scanning
Supply ChainSBOM

Generates an SPDX JSON SBOM (Syft) and uploads it as an artifact.

  • Artifacts: open the latest run → download sbom → sbom.spdx.json
Quick Demo

Local run:

  • docker build -t devsecops-ci-pipeline:local .
  • docker run --rm -p 8080:8080 devsecops-ci-pipeline:local
  • curl http://localhost:8080/health
